# C-CDA Online Search Tool

This folder contains the HTML pages (and pdfs) which were provided as part of the C-CDA navigation tool project, initially released in January 2021 and last updated in February 2026. It was originally managed in a separate repository (https://github.com/jddamore/ccda-search) but was migrated in 2026 to an official HL7 repository managed by Structured Documents Working Group (SDWG). The original project had scripts for parsing out and creating the webpages, but only the final HTML files have been added to this HL7 repository.  

The project is available: http://www.hl7.org/ccdasearch/ (note that all web pages contains date of last update)

**IMPORTANT:** Information contained in this repository is publicly accessible on the internet, but it is not open-source. Please see LICENSE.txt for more information on HL7's copyright to this information. 

## What's here

- An index page HTML page which allows for search of all templates in C-CDA 2.1.0.7 and C-CDA Companion Guide 4.1.1 (index.html) 
- A backup index page for organization who cannot load the JavaScript for table in original index (basic.html)
- All the C-CDA 2.1 and Companion Guide tempaltes separated as pdfs (/pdfs)
- All the C-CDA 2.1 and Companion Guide templates seprated into individual html pages (/templates)
